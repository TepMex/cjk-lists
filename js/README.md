# cjk-lists (JavaScript / TypeScript)

```sh
npm install cjk-lists
bun add cjk-lists
```

```js
import { zh } from 'cjk-lists';
import { top1000 } from 'cjk-lists/zh/subtlex-ch';

console.log(zh.hsk2.hanzi.level1.length);
console.log(top1000[0]); // 的
```

See the [repository README](https://github.com/TepMex/cjk-lists) for the
full API, sources, and Python / Rust / Java / Kotlin packages.
